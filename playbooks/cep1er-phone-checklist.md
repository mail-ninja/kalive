# cep1er — sjekkliste (tether + åpent gjestenett)

Mål: telefonen er «fronten» mot fiendtlig WiFi. Gå punkt for punkt. Kryss av.

## A. Akkurat nå (mens tether er på)

- [x] **USB-debugging AV**  
  Innstillinger → Om telefonen → trykk Byggnummer 7× bare hvis du trenger utvikler; ellers:  
  Innstillinger → System → Utviklermuligheter → **USB-debugging = AV**
- [ ] **USB-modus:** bare «USB-tethering» / «Filoverføring» når du trenger det; trekk ut kabel når ferdig
- [ ] **Bluetooth AV** hvis ikke i bruk
- [ ] **NFC AV** hvis ikke i bruk
- [ ] **Skjermlås** på (PIN/biometri du kontrollerer)
- [ ] Ingen ukjent **VPN**-app aktiv
- [ ] Ingen «WiFi accelerate / free VPN / security cleaner» du ikke installerte selv

## B. Apper og bakdører (15–20 min)

- [ ] Apper → sorter etter **sist installert** — fjern alt ukjent
- [ ] **Tilgjengelighet** (Accessibility): bare tjenester du kjenner (ingen rare «helper»)
- [ ] **Enhetsadministratorer** / Device admin: bare kjente (Find My, bank, osv.)
- [ ] **Standard-apper** for SMS, telefon, nettleser = det du forventer
- [ ] **Varsler** fra ukjente apper som ber om tillatelser
- [ ] Play Protect / app-butikk-skanning på
- [ ] Systemoppdatering sjekket (kan vente til renere nett)

## C. Etter gjestenett

- [ ] Glem gjestenett-SSID hvis du ikke trenger den igjen
- [ ] Bytt passord for kontoer du **faktisk brukte** på telefonen på det nettet (fra rent nett senere)
- [ ] Vurder reboot av telefon etter du er av gjestenettet

## D. Rask «lukt-test» (dårlig tegn)

- Batteri/varme uten bruk  
- Høy data uten at du surfer  
- Overlay som ber om PIN  
- Nye admin-apper  
- SMS til ukjente kortkoder  

Ved flere røde flagg: **ikke** factory reset uten backup-plan for 2FA — men vurder ren install / reset når du er hjemme.
